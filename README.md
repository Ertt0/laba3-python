# Каталог учебных аудиторий

## Описание проекта

Проект представляет собой каталог учебных аудиторий. Он позволяет создавать, хранить, искать и удалять информацию об аудиториях.

Для каждой аудитории хранятся следующие данные:
- **ID** — уникальный идентификатор;
- **Название** — название аудитории;
- **Категория** — тип аудитории;
- **Год** — год основания или создания;
- **Специализация** — направление использования аудитории;
- **Корпус** — расположение аудитории.

## Основные возможности

- Создание и проверка объектов аудиторий.
- Добавление аудиторий в каталог.
- Получение аудитории по ID.
- Удаление аудитории по ID.
- Поиск аудиторий по категории.
- Поиск аудиторий по названию без учёта регистра.
- Получение количества объектов в каталоге.
- Перебор объектов каталога в отсортированном по ID порядке.
- Проверка наличия аудитории по ID.
- Сохранение каталога в JSON-файл.
- Загрузка каталога из JSON-файла с проверкой корректности данных и версии формата.

## Используемые технологии

- Python 3.12+
- Pydantic — создание моделей и проверка данных.
- JSON — хранение данных.
- pytest — тестирование.
- uv — управление зависимостями и запуск проекта.
- mypy — статическая проверка типов.
- Ruff — проверка и форматирование кода.

## Установка и запуск

Клонировать репозиторий или перейти в папку проекта.

Установить зависимости:

```bash
uv sync
```

Запустить проект:

```bash
uv run python -m src.classrooms
```

При запуске создаётся каталог, после чего в него загружаются данные из файла `src/classrooms/catalog.json`.

## Тестирование

Запустить все тесты:

```bash
uv run pytest
```

Запустить тесты с подробным выводом:

```bash
uv run pytest -v
```

## Проверки качества кода

Проверка типов:

```bash
uv run mypy src tests
```

Проверка стиля:

```bash
uv run ruff check .
```

Проверка форматирования:

```bash
uv run ruff format --check .
```
